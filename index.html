项目经历

续页 · 防剧透阅读助手

个人项目 · React、TypeScript、FastAPI、SQLite

针对长篇叙事文本问答可能泄露后续情节的问题，设计并实现了基于阅读进度的问答系统。系统以读者标记的句子为检索边界，在已读文本中检索证据，生成回答后核验引文，并将引文定位至 PDF 原页。

对于持续追踪的问题，系统根据新增的已读段落更新答案并保存历史版本。读者回退书签后，系统展示与该进度对应的版本。

GitHub 仓库样书试读指南

人脸识别考勤系统

本科毕业设计 · PyQt5、YOLOv8n-face、SQLite

独立设计并实现基于人脸识别的桌面考勤系统。系统采用 YOLOv8n-face 检测人脸，结合 face_recognition 完成身份识别，并将考勤记录存入 SQLite。通过设置同一人员连续签到的最小时间间隔，抑制重复记录。系统支持按角色管理权限、人工补录及考勤报表导出。

苏东沿海风场预报订正

大学生创新训练项目 · Python、PyTorch、U-Net

基于欧洲中期天气预报中心（ECMWF）的十米风预报数据，比较 ULR、DAM、QM 和 U-Net 四种方法在江苏东部沿海地区的预报订正效果，预报时效为 1 至 7 天。我负责风速与风向数据的清洗、归一化和时空特征提取，并使用 PyTorch 实现和训练 U-Net 模型。
